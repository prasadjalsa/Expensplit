ExpenSplit Documentation

Everything you need to track group expenses, split costs, and settle up — no sign-up required.

What is ExpenSplit?

ExpenSplit is a lightweight, single-file web app for splitting group expenses — trips, flatmates, events, dinners. It works like Splitwise but lives entirely in one HTML file that you can host on GitHub Pages and share with anyone.

Key characteristics:

  • No sign-up or login — access is controlled by a room link.
  • Real-time sync — all group members see changes instantly via Firebase.
  • Flexible splits — equal, unequal, percentage, or share-based.
  • Smart settlements — minimises the number of transfers needed to clear all debts.
  • Sign-off flow — each member acknowledges the expense list before settling.

Rooms & Sharing

A room is a unique workspace shared by your group. Every expense, balance, and settlement lives inside one room. Multiple rooms can exist independently — one per trip, household, or event.

How rooms work

  • When you open ExpenSplit for the first time, a random Room ID is generated automatically and stored in your browser.
  • The Room ID appears in the URL as #room=abc123xyz and on the People tab.
  • Anyone who opens the same URL lands in the same room and sees the same data.
  • Rooms are backed by Firebase Firestore — data persists in the cloud, not just your browser.
Tip Tap the 🔗 button in the header (or Copy Link on the People tab) to copy your room URL and send it to your group on WhatsApp, Telegram, or email.
Note Keep your room link private — anyone with the link can view and edit the data.

How to: Set up a group

  1. Open the app and name the group
    Tap "Tap to add a name" under the header title — type a name (e.g. "Goa Trip 2025") and press Enter. You can also do this from Settings → Group / Expense Name.
  2. Add all members
    On the People tab, type each person's name in the input field and tap Add (or press Enter). Repeat for every member. Each person gets a colour-coded avatar with their initials.
  3. Share the room link with the group
    Tap Copy Link on the People tab (or the 🔗 button in the header). Send the copied URL to your group — they open it and immediately join the same room.
Tip Add everyone before adding expenses — people can only be assigned to expenses if they exist in the group.

How to: Add an expense

  1. Open the Expenses tab and tap +
    Switch to the Expenses tab. Tap the green + button at the bottom-right of the screen.
  2. Fill in the description, amount, and date
    Enter a short description (e.g. "Hotel", "Dinner"). The app auto-picks an emoji icon based on keywords. Enter the total amount and confirm the date (defaults to today).
  3. Set who paid
    Under Paid By, select the person who paid from the dropdown. If multiple people paid, tap + Add payer and enter each person's contribution. The hint turns green when the payer amounts exactly match the total.
  4. Choose a split type and configure it
    Pick how to divide the cost among members (see Split types below). The hint below the list shows whether the split is valid.
  5. Tap Save Expense
    The expense appears in the list with a summary badge. All group members see it instantly.
Tip Tap any expense card to view a full breakdown. From the detail view you can Edit or Delete it.

How to: Choose a split type

ExpenSplit supports four ways to divide an expense. Choose the one that matches the situation:

Type When to use How it works
Equal Everyone pays the same Total ÷ number of selected members. Check or uncheck people to include/exclude them.
Unequal Each person owes a specific amount Type the exact amount for each person. The hint shows the running total and how much is left to assign.
% Split by percentage Type a percentage (0–100) for each person. Percentages must sum to exactly 100%. Uncheck members to exclude them.
Shares Proportional split (e.g. 2 adults, 1 child) Assign a number of shares to each person (e.g. 2, 2, 1). The cost is divided proportionally. The hint shows the amount each person will owe.

Percentage split step-by-step

  1. Select "%" in the split tabs
  2. Type each person's percentage directly in their input field
    Click or tap the number field next to a person's name. Type the percentage value (e.g. 40). The field accepts free text so you can edit freely.
  3. Check the hint below
    It will show the running sum. Once all percentages add up to 100 the hint turns green.
Common mistake Clicking the input field directly — not the row background — ensures the checkbox isn't accidentally toggled. Tap the number box itself to start typing.

How to: Handle multiple payers

Some expenses are paid by more than one person (e.g. two people split a hotel bill at the counter).

  1. In the Add Expense form, go to the Paid By section
  2. Select the first payer and enter their amount
  3. Tap "+ Add payer" to add a second row
    A new payer row appears. Select the second person and enter the amount they paid.
  4. Confirm the hint is green
    The payer total must equal the expense total. The hint shows the difference if they don't match.

How to: Sign off on expenses

Before settling, each member should confirm that the expense list is complete and correct from their perspective. This prevents disputes later.

  1. Go to the Settle Up tab
    The Sign-offs card appears at the top showing the confirmation status for each member.
  2. Each member taps their own Confirm button
    This records the date of their confirmation. The badge turns green: ✓ Confirmed · 14 May.
  3. Once everyone is confirmed, proceed to settle
    The summary shows "✓ All N members confirmed". Now follow the Suggested Settlements to pay each other.

Sign-off statuses

  • Pending — member hasn't confirmed yet.
  • ✓ Confirmed — confirmed and no new expenses since.
  • ⚠ N new expenses added — confirmed earlier but new expenses were added after. Member should Re-confirm.

Any member can tap Revoke to withdraw their confirmation if they spot a mistake.

How to: Record a payment

The Settle Up tab shows the minimum number of transfers needed to clear all balances.

  1. Review the Suggested Settlements list
    Each row shows who pays whom and how much (e.g. "Ravi → Priya ₹1,200").
  2. Make the payment outside the app
    Transfer the money via UPI, bank transfer, cash, or any method you prefer.
  3. Tap Settle on that row
    A "Record Payment" dialog opens, pre-filled with the amount. Adjust if needed, add a note (e.g. "GPay"), and tap Confirm Payment.
  4. Repeat for each suggested transfer
    Once all transfers are recorded, the app shows "🎉 All settled up!"
Tip The smart settlement algorithm minimises transfers. For example, 5 people with complex debts may only need 4 or fewer payments to fully balance out.

How to: Share the room with your group

  1. Tap the 🔗 button in the header, or Copy Link on the People tab
    The room URL (e.g. https://yourname.github.io/expensplit.html#room=abc123) is copied to your clipboard.
  2. Send the URL to your group
    Paste into WhatsApp, Telegram, iMessage, email — wherever your group communicates.
  3. Group members open the link
    Their browser loads the same room. The ● Live pill confirms they're connected. All existing data loads immediately.
Important If a group member opens the base URL (expensplit.html) without the #room= hash, they will be placed in a different room. Always share the full link including the hash.

How to: Change settings

Tap the ⚙️ gear icon in the header to open Settings.

Change the group name

Either tap "Tap to add a name" in the header to edit inline, or open Settings → Group / Expense Name and type a new name. Tap Save.

Change the currency symbol

Open Settings → Currency Symbol. Type your preferred symbol (e.g. $, €, £, ¥) and tap Save. All amounts displayed throughout the app update immediately.

Remove a group member

On the People tab, tap the ✕ button next to a member's name. If that person is part of any expense, you'll be asked to confirm before they are removed.

How to: Reuse the app for a new trip

Once a group has settled up completely, you can clear the data and reuse the same room for a new trip.

  1. Make sure all payments are recorded
    Go to Settle Up and record every suggested payment so the history is preserved before clearing.
  2. Open Settings (⚙️) and tap Clear All Data
    Confirm when prompted. All expenses and settlements are deleted.
  3. Update the group name
    Tap the group name in the header and type the new trip name (e.g. "Kerala Trip 2026").
  4. Start adding new expenses
    Group members, currency, and the room ID are all preserved — no need to share a new link.
Tip Want to keep a permanent record of the old trip? Before clearing, open the browser's developer tools → Application → Firestore or take a screenshot of the Settlement History.

Frequently Asked Questions

Is my data private?

Data is secured by obscurity — only people with the room link can access your group's data. The Room ID is a random 12-character string that is practically impossible to guess. That said, do not share your room link publicly (e.g. in a public post or tweet).

What if I lose the room link?

The Room ID is saved in your browser's local storage. If you open the app on the same browser/device you created the room on, it will reconnect automatically. The Room ID is also displayed on the People tab — copy it and store it safely.

If you open the app on a new device without the link, a new empty room will be created. Ask a group member who has the original link to share it again.

Can multiple people add expenses at the same time?

Yes. The app uses Firebase Firestore's real-time sync. When any member saves an expense, all other open browsers update automatically within seconds. A ● Live pill in the header confirms the connection is active.

What does ● Live / ● Offline mean?

● Live — the app is connected to Firebase and changes sync in real time.

● Offline — the Firebase connection failed (no internet, or the Firestore rules are blocking access). The app falls back to the last data saved in your browser's local storage.

What's the difference between the four split types?

Equal — splits the total evenly among selected people. Best for most shared meals or bills where everyone owes the same.

Unequal — you type the exact rupee/dollar amount each person owes. Use when people ordered different items of different values.

% — type a percentage for each person (must total 100%). Useful when contribution ratios are known but exact amounts vary.

Shares — assign relative shares (e.g. 2, 2, 1 for two adults and a child). The app calculates proportional amounts automatically.

How does the smart settlement work?

The app calculates each person's net balance (total paid minus total owed). It then uses a debt-minimisation algorithm to find the smallest number of transfers that brings every balance to zero. In most groups of 4–6 people this reduces the number of payments significantly compared to settling pair-by-pair.

Can I edit or delete an expense after saving?

Yes. Tap the expense card to open its detail view. Tap Edit to modify any field, or Delete to remove it. Deleting an expense will mark any group members who previously signed off as needing to re-confirm.

What does "Re-confirm needed" mean in Sign-offs?

A member confirmed the expense list at a point in time, but new expenses were added (or deleted) after they confirmed. The ⚠ N new expenses badge prompts them to review the changes and tap Re-confirm if they agree.

Does the app work without internet?

Partially. The app loads its last known state from the browser's local storage when offline. You can view existing data, but changes won't sync to other members until the connection is restored. Firebase Firestore may also buffer writes locally and replay them when reconnected.

How many people can be in a group?

There is no hard limit in the app. Practically, groups of 2–20 people work well. Very large groups may make the settlement list harder to read, but the data and calculations remain correct.

What happens when I tap Clear All Data?

All expenses, settlements, and sign-offs are permanently deleted from both the browser and Firebase. The group name, member list, and currency symbol are preserved. This action cannot be undone — record any important history (e.g. screenshots) before clearing.

Can I use this for multiple trips simultaneously?

Yes — open the app in different browser tabs or use different browsers/devices. Each new instance without a #room= hash generates a fresh room. To switch between rooms, use different room links.

The percentage inputs keep deselecting the person — what do I do?

Click or tap directly on the number input field itself (not the row background). The row background acts as a checkbox toggle — clicking anywhere on the row except the input will check/uncheck the person. Targeting the input box directly avoids this.

Can I change the currency mid-trip?

Yes. Open Settings → Currency Symbol and update it. The new symbol is applied to all displayed amounts immediately. Note that this is a display-only change — the underlying numbers are not converted. If your group used two currencies, track them as separate rooms or convert amounts manually before entering.
